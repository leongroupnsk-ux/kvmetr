## Renovation wireframe prototype

Статический прототип (HTML/CSS/JS) по описанию вайрфреймов:

- `index.html` — главная
- `case.html` — карточка кейса (ЖК «Рябиновый»)
- `blog.html` — каталог статей
- `article.html` — страница статьи

### Как запустить локально

Любой статический сервер. Например:

```bash
cd Sites/renovation-wireframe
python3 -m http.server 5173
```

Откройте `http://localhost:5173`.
