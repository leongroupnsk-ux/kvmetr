Я собрал структуру всех 4 страниц и общие интерактивы из script.js, плюс стили/токены из styles.css и список ассетов. Осталось быстро посмотреть vite.config.js, vercel.json и что лежит в dist/, чтобы описание было действительно “полным” по всем элементам репозитория.

Общая структура проекта (что это)
Статический прототип сайта ремонтной компании (HTML/CSS/JS) с мультистраничной сборкой через Vite.

Страницы: index.html, case.html, blog.html, article.html
Стили: styles.css (единый для всех страниц)
Логика/интерактив: script.js (единый модуль для всех страниц)
Графика: assets/*.svg
Сборка: dist/ (результат vite build)
Конфиги: vite.config.js, vercel.json
Зависимости: package.json, package-lock.json, node_modules/
Файлы и их назначение
